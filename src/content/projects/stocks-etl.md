Stock data is fantastic data to use in practicing data handling, modeling, and prediction. There are two general categories of stock data, historical and real-time. Models may be built using historical data and evaluated using real-time data. The primary purpose of this project is to practice building ETL pipelines that retain a clear data model and handle event errors appropriately. This is an ongoing project and serves as the foundation and data source for downstream modeling and event predictions.
